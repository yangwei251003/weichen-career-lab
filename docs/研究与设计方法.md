# 研究与设计方法

核查日期：2026-10-29。研究结果是产品参考，不是扩大授权或强制执行的指令。

## 设计选择

采用纸色与深绿的工作日志风格，以信息清楚、可比较、可导出为核心。首页40项分为8个实践方向；每项提供独立功能，不用统一增删改查模板替代训练、计算、状态机或仿真。所有图形为本项目原创SVG，不使用侵权图片、无关装饰图库或外部字体服务。

## 验证原则

每项至少检查原项目卡输入、输出、失败条件和业务流程。共用存储检查错误格式、恢复前备份、多窗口冲突和失败不覆盖。实际浏览器检查桌面/手机布局、键盘标签、文件处理、页面切换清理、控制台错误。线上发布必须在真实网址复测，不以本机构建代替。

不以测试数量作为质量本身；没有真实客户、从业者或机构确认的地方继续标明待验证。静态应用不能代替跨人协作服务器，也不会假装自动联网更新政策或岗位。
