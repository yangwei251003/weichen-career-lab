- 文件：src/groups/g6/logic.js 的 businessSummary 客户汇总。

- 影响：原普通对象映射可能读取继承属性，触发汇总异常；客户文本不应改变程序对象行为。
- 修复：改为无原型映射，新增这些客户名的汇总回归。不是导入原型字段；core本来就会拒绝危险对象键，漏洞来自合法字符串被用作普通对象键。
