## 五个项目的专用工作流

### 36：安全模拟与前后解释

- 体验前预测 → 闭合6V/12Ω回路 → 串联第二只电阻 → 四旋翼竖直推力实验 → 体验后回答与自己的解释。
- 产生短路时，图中旁路绕过全部负载；停止给出虚假的安全电流，清楚说明错误。
- 悬停同时检查合力与初速度；半秒步进可观察加速度、速度和高度，达到边界会停止。
- 匿名保存秒数、前后回答、三关完成情况、错误探索和解释；没有儿童姓名或账号字段。
- 教学负责人、核查日期与适合年龄/讲解修订记录独立保存。下载讲解与体验记录。

软件验收不能代替真实教学负责人核查或课堂理解验证。3—5分钟是设计目标，本轮自动化脚本不是学生的实际完成用时。

### 37：训练、生活情境与比赛节奏

- 保留已核净计时2:56:31与42.195km，不伪造分段。预设训练日志全部标“示例”。
- 本人日志包含距离、时长、类型、目标、实际完成/未达目标原因、恢复感受、睡眠、疲劳和学习负荷。
- CSV支持带引号、逗号与嵌入换行；导入前映射列、选择km/m/mi和秒数/时分秒、预览，再确认追加。重复日期/距离/时间跳过；导入数据保留“待核”性质。
- “全部”仅列记录，不合并统计。选择单一数据性质后查看周图；未知睡眠等不按0处理。
- 本人与示例分段分图、分开求和。示例分段不会使本人比赛显示“已对齐”；每类距离不能超过比赛距离。
- 比赛总目标、过程复盘和待向本人/专业教练讨论的问题可以保存；输出CSV与Markdown。

不提供医学或训练处方；未连接手表、运动账号或实际教练。CSV格式兼容性以导入预览为准。

### 38：一个校园科普活动的路线服务

- 原始云游地图只有个人事实、作品截图说明与本人上线确认，本轮在相关目录没有找到可核实的源码或线上地址。主Agent确认按独立场景扩展实施；**未修改或接通原网站**。
- 选择“校园电学与无人机科普半日体验”作为唯一预设场景，地点与坐标全部模拟。
- 点击点位选中、开启地图布点、点击空白设置坐标；也可键盘输入0—100坐标。
- 地点关联任务、人员/资源、来源、核查日期、步行与停留分钟；可重排、暂停和删除。
- 时间按参与站点重新计算，首点步行按0处理，跨午夜明确“次日”；重排后提示复核步行时间。
- 保存完成、退出或未开始反馈；未完成必须说明原因。导出活动行程、时程CSV和原创SVG。

尚无真实校园许可、路线试走或目标用户反馈；坐标不提供导航、真实距离或飞行许可。继续投入前仍需找回原项目并核实授权、负责人和真实体验。

### 39：有出处的技术解释

- 一次一个受众问题，记录核心观点与适用边界；内容片段关联事实、旁白、画面类型、来源/许可与秒数。
- 事实区分已核、待核、示例假设。引用不存在、待核事实或缺少真实素材许可时会提示；已被引用的事实不能直接删除。
- **复用01/13**：选择它们导出的单项目JSON，使用原项目校验器核验，预览并选择条目后追加。不会覆盖来源项目，不把旧记录确认升级为新稿件已核实；13模拟条目仍为示例。
- 人工确认保存当前内容签名；事实、文本、定位、顺序或画面信息改动后，当前版本须重核。
- 导出完整稿件/事实清单以及连续时间轴SRT；可以记录读者复述、误解和修改动作。

未调用AI生成接口、未合成视频、未自动发布。SRT为用户填入秒数的朗读草稿，不等于音频实测字幕。外部素材许可文字是记录，不是自动许可鉴定。

## 云端CI暴露的问题与修复（2026-10-30）

Ubuntu 24.04统一浏览器回归暴露了37导入流程的异步时序问题：文件选择事件返回时，`File.text()`可能尚未完成；测试立即检查表单存在性会错过它，而解析后的页面重绘又把导入区域收起。另一个测试辅助函数将布尔`open`属性的空字符串错误视为关闭。

修复后，CSV解析结果存在时导入区保持展开，映射预览重绘后仍可见；测试先等待目标挂载，按`open`属性是否缺失判断折叠状态，明确断言可见后进行正常操作。回归在隔离浏览器中暂缓测试CSV的原生读取，先确认解析未完成，再释放读取并验证映射区自行显示；没有强制点击或绕过可见性。

同次检查修复了分段分图时误读原始记录不存在的`pace`属性：现在直接由秒数/距离计算，浏览器断言两类分段图均无NaN、4分钟/km数据标签与有限柱高正确。37项Node测试和五项目隔离浏览器业务回归再次通过；云端重跑由主Agent负责，不能把本地复测写成云端已通过。
