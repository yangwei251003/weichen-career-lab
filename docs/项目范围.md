# 40个项目的原始验收范围

本清单保留批准的原始项目卡文字，复选框留给后续真实使用者做业务与能力验收，未将模拟试用当真人验证。40项软件实现与自动化证据见[实施进度](实施进度.md)，逐项可用流程见[应用索引](40个应用索引.md)。

实现调整：19提供原能策V3/CNY导出适配、复算与访谈/观察记录，未伪造3次真人访谈；38未找到可核实的旧网站源码，已实现独立离线场景延伸，不宣称改造原站。其余条件项目以明确标注的模拟数据或空白记录提供软件工作流，真实客户、设备、公司数据待本人授权录入。
## 01 职业成果证据库

10条左右真实种子证据、增删改查、标签、来源复制和本地导出；不做自动简历投递。

- [ ] 能在1分钟内找到指定成果及其来源
- [ ] 同一成果的本人贡献和边界始终同时显示
- [ ] 导出再导入后记录数量和文本一致

## 02 实习与岗位研究台

先录入8—12个岗位样本，按电力方案、应用支持、海外支持分类；历史样本明确标记。

- [ ] 每个岗位均显示发布日期和适用届别
- [ ] 硬性不满足与可学习项分开
- [ ] 能从一个JD追溯至至少两项本人证据或缺口

## 03 考研—就业比较器

手动维护3—6个方向，与一项真实就业机会对照；不固定未经验证的院校推荐。

- [ ] 仅推免项目不会进入统考候选
- [ ] 要求工作年限的方向会明确拦截应届假设
- [ ] 调低预算或改变诊断成绩时能看出决策为何变化

## 04 能力练习与验收台

先建技术讲解、表格分析、英语演示各一项练习；每项保留原始证据。

- [ ] 每项能力都有可观察动作而非笼统熟练标签
- [ ] 保存失败记录和后续修正
- [ ] 能独立解释一项计算与一次故障定位

## 05 人生选择情景账本

就业、读研、创业三张开放决策卡；事实不足时清楚显示待收集。

- [ ] 每项选择都有失败后可执行的退路
- [ ] 新证据与原判断分别保存
- [ ] 能说明改变结论的具体条件

## 06 产品资料与参数比较台

两款产品、三个场景、10项核心参数；人工录入和人工复核。

- [ ] 每个参数能回到原始来源
- [ ] 不同单位和测试条件不会被直接排名
- [ ] 资料更新后能找到受影响的比较卡

## 07 客户需求访谈教练

三个角色：培训负责人、设备运维人员、行业方案负责人；保存练习而非伪造订单。

- [ ] 摘要明确区分原话和解释
- [ ] 能找到预算/流程/验收标准中的缺口
- [ ] 本人能独立完成10分钟访谈而不连续推销功能

## 08 方案成本与价值计算器

一个产品方案、三种情景、可下载公式和输入；待条件具备再启动。

- [ ] 人工复算与输出相符
- [ ] 收入为零、回款延迟和成本上升情景可运行
- [ ] 单位与期间改变时不会静默混算

## 09 方案演示与材料检查器

先支持文本粘贴与检查清单，自动生成只做草稿；复用01号证据和06号参数。

- [ ] 能发现预置的无来源数字和过期参数
- [ ] 实际计时后再记录时长结果
- [ ] 未核实内容不会被包装成已验证成果

## 10 客户跟进与项目机会台

5—10个授权项目的小范围试用；未获授权前只保留演示数据。

- [ ] 同一事项有唯一负责人和下一步
- [ ] 删除/导出权限符合试点约定
- [ ] 连续两周使用后能够核对漏跟进数量

## 11 教学与活动交付台

单场活动模板、责任人、资源和复盘；不做收费报名或复杂教务系统。

- [ ] 两个活动占用同一设备/场地时显示冲突
- [ ] 每项关键准备有人确认
- [ ] 活动后能回溯遗漏与改进而非只显示完成率

## 12 器材借还与维护台账

10件以内器材手工编号与借还；扫码仅在记录流程稳定后加入。

- [ ] 同一器材不能同时借出两次
- [ ] 停用设备不能显示可借
- [ ] 退回缺件和维修完成都有独立记录

## 13 课程与宣传事实中心

首期主项目：本机事实CRUD、冲突识别、有效期提醒、人工确认、导出与备份；与01号证据记录共用工作台。

- [ ] 96与112两条待核实记录显示同组冲突
- [ ] 缺确认人、来源、日期或有效期的记录不能当可发布事实
- [ ] 过期记录被保留但不得进入当前发布稿
- [ ] 任何冲突处理保留另一条原记录及说明

## 14 物料与交付检查器

文件清单导入、属性检查和人工状态；先不做自动修图、刀模生成和下单。

- [ ] 1536×1024像素用于6×4米时正确显示约6.5PPI
- [ ] 1:10与1:1文件不会误报同一目标尺寸
- [ ] 未打样状态不会显示生产通过

## 15 团队任务与交接助手

一个项目、5—10项任务、简短交接导出；不做全公司绩效系统。

- [ ] 新人只读任务卡能复述目标和验收
- [ ] 前置未完成时不会误标后置完成
- [ ] 每项共享成果有明确唯一负责人

## 16 巡检问题与整改闭环台

模拟演示版：10个合成案例、状态流转和证据导出；不接真实设备或电网系统。

- [ ] 未经复查不能标为闭环
- [ ] 所有案例显著标明模拟
- [ ] 能回放一次误报被驳回和一次处理后复查

## 17 无人机故障学习案例库

5个学习案例、来源和边界；以检索与复习为主，不做自动诊断器。

- [ ] 更换机型后不会套用不相容步骤
- [ ] 猜测原因与已证实原因分开
- [ ] 每个操作建议都有适用手册或指导依据

## 18 巡检任务规划沙盘

蓝图：一个二维合成场景、有限任务点和规则规划；不先追求复杂自主算法。

- [ ] 电量不足或任务不可达时明确报告失败
- [ ] 路径结果能解释关键约束
- [ ] 界面和导出均标明教学模拟

## 19 能策 Pilot 行业验证版

延续版：先做3次有记录的访谈与一次观察性试用，按证据只改一个最高价值问题。

- [ ] 评审人可复现关键计算并指出用途
- [ ] 源数据和电价口径可追溯
- [ ] 明确区分软件测试、模型比较与客户价值验证

## 20 行业数据标注与评测台

条件项目：先做小样本数据审计和评测，不先训练大模型。

- [ ] 重复或近重复样本不能跨训练测试静默泄漏
- [ ] 指标能手工复算小样本
- [ ] 报告包含误报、漏报、样本量和失败场景

## 21 英语技术演示陪练

三种场景：产品介绍、需求追问、故障解释；可先纯文本与本地录音记录。

- [ ] 无稿说明产品适用与限制
- [ ] 能听懂并复述一个模拟客户需求
- [ ] 遇到未知参数会明确待确认而非编造

## 22 双语知识库与版本检查器

小版：30个术语、两份短文档和人工对应关系；不做全网自动翻译。

- [ ] 中文参数变化会标记关联英文待审
- [ ] 型号和单位不被翻译器改写
- [ ] 未经审校内容始终标为草稿

## 23 经销商培训与考核包

条件项目：一个机型、一个培训班、三项实践任务；先输出文档包而非开发平台。

- [ ] 学员能独立完成指定演示任务
- [ ] 错误步骤会被具体记录和复测
- [ ] 资料版本与所用产品对应

## 24 海外区域机会研究台

条件项目：单一区域单一场景的研究卡；不开发全球机会预测平台。

- [ ] 每条关键判断有地域、日期和出处
- [ ] 潜在需求与已核实采购分开
- [ ] 报告包含不进入该区域的理由

## 25 海外报价与履约情景沙盘

蓝图：一单虚构设备交易、三种情景、可复算公式。

- [ ] 回款晚于支出时显示资金缺口
- [ ] 单位、币种和期间明确
- [ ] 变更一项假设能追溯到结果变化

## 26 合作关系与贡献记录簿

5—10段真实合作的私人记录，不强制录入电话、邮箱等联系方式。

- [ ] 每条评价有具体合作事件支撑
- [ ] 只提醒自己的承诺而不监控对方
- [ ] 可按对象完整删除或导出记录

## 27 合伙人试合作工作台

条件项目：一次有限周期试合作的文档和任务表，不建立复杂合伙平台。

- [ ] 双方都能说明自己的责任和退出方式
- [ ] 至少完成一个真实交付并复盘分歧
- [ ] 贡献记录可共同核对而非单方定性

## 28 个人现金与创业承受力计算器

本地手工表格或模块；先记录现金，后做情景，不预设未确认的收入金额。

- [ ] 收入为零时能显示必要支出可覆盖期
- [ ] 一次性与持续支出不会混算
- [ ] 所有结果标明本人输入和假设

## 29 客户问题与付费实验台

记录版现在可做：访谈与实验卡；先人工验证一个问题，再决定是否开发。

- [ ] 问题、解决方案和证据分别记录
- [ ] 每个实验有时间/投入上限和停止条件
- [ ] 记录拒绝和不用的原因而不只保留好评

## 30 小团队经营看板

条件项目：单业务线经营复盘；先按真实口径做表格，再考虑应用。

- [ ] 营业额、利润代理与到账现金清楚分列
- [ ] 汇总能核对到原始订单
- [ ] 退款、延期和坏账假设不会消失

## 31 行业采购与岗位观察库

10条人工精选记录、三个主题和日期提醒；不承诺自动联网更新。

- [ ] 每条记录区分事实和推断
- [ ] 历史岗位显著标注届别
- [ ] 每周至少筛出一项行动或明确无行动价值

## 32 创业机会证据评估台

先评估3个候选：培训资料一致性、交付管理、行业方案支持；不同时启动。

- [ ] 每个机会能回答谁付费、为啥现在、怎么交付
- [ ] 缺关键证据时显示未验证而非低分通过
- [ ] 一次反对证据能触发复审

## 33 预测与判断复盘账本

5条关于学习、需求、交付的可检验判断；手动到期复盘，不自动预测。

- [ ] 原始判断与后续修订分别保存
- [ ] 模糊不可检验判断会提示重写
- [ ] 到期无法判定有独立状态

## 34 企业经营情景游戏

小版：三种行动、五个回合、可复算现金规则；不做大型经营游戏。

- [ ] 规则可读、结果可复算
- [ ] 高收入但回款晚的公司可能现金不足
- [ ] 每局结束能解释一个取舍

## 35 理论与论证地图

一个问题的节点/关系清单和引用，不开发通用知识图谱平台。

- [ ] 每个结论能找到依据或标为假设
- [ ] 反对证据与支持证据同等可见
- [ ] 能口头解释理论的适用边界

## 36 无人机与电学互动教学小游戏

一个3—5分钟的安全模拟关卡，无账号、离线可用。

- [ ] 错误操作在模拟中有清楚解释
- [ ] 教学负责人核对内容
- [ ] 参与者能解释目标概念而非只通关

## 37 跑步训练与比赛复盘工具

个人离线日志与比赛复盘页，优先导入已有导出格式。

- [ ] 数据缺失与估计值明确显示
- [ ] 能核对比赛分段和总时长
- [ ] 记录目标未达成原因，不只展示最好成绩

## 38 云游地图的场景延伸版

条件项目：复用现有网站，只延伸一个可验证的文旅/活动场景。

- [ ] 至少一位目标用户完成真实路线体验并反馈
- [ ] 景点时效信息有来源和日期
- [ ] 失效地点可及时撤下或标记

## 39 技术科普内容工作台

一次只做一篇技术解释，复用13号事实中心与01号成果库。

- [ ] 关键参数能回到来源
- [ ] 模拟/生成画面有适当说明
- [ ] 目标读者能复述核心知识与限制

## 40 小型硬件需求验证台

蓝图：先访谈和纸面/低风险模型；需要实际EDA时再按用户偏好采用嘉立创专业版的专门流程。

- [ ] 用户能完成预定任务且记录失败
- [ ] 每项设计有需求依据
- [ ] 安全与工程未验证项始终显著保留
