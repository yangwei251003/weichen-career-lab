# 模块开发契约 v1

每组目录src/groups/g1至g8，各5个项目。每组index.js导出`apps`对象，以两位项目ID为键；各值`{ mount(root,ctx) }`，mount可返回清理函数（timer、录音、事件）。禁止直接改全局导航。

ctx包含：
- `id`, `meta`(catalog卡片), `store`: `get()`返回深拷贝当前项目data；`save(data)`验证通用JSON并以修订号保存，冲突/配额抛错；`reset()`仅用户明确重置时使用。各模块用default state并持久化前合并schema；不在mount时覆盖已有数据。
- `notify(message,kind='success')`, `confirm(message)`原生确认同步布尔；`download(filename,text,mime)`。
- `onCleanup(fn)`登记清理；`today()`本地YYYY-MM-DD。

共享模块`../../core.js`导出（从src/groups/g1/index.js路径）：
- `esc(v)`HTML/属性转义；`uid()`；`today()`；`number(v,{min,max,label})`空/NaN/范围不合法抛中文Error；`formatNumber(v,digits=2)`。
- `field(name,label,value='',options={})`输出label+input/textarea/select。options: type(text/number/date/url/textarea/select), required, min,max,step,placeholder,help,options:[string或{value,label}], wide(boolean)。fieldset请模块自己渲染。
- `formValues(form)`返回Object.fromEntries(FormData)，数字仍是字符串；`button(text,action,kind='primary')`输出type=button data-action；`empty(text)`；`stat(label,value,note='')`；`badge(text,kind='')`；`table(headers,rows)`输出表格，headers自动转义，rows的cell视为已安全HTML（每个用户内容调用esc）。
- `download`, `csv(rows)`其中rows二维数组，CSV公式注入防护；`toMarkdown(title,sections)`可不用；`safeUrl(url)`仅http(s)返回原值，否则''。

通用CSS class：`panel`、`panel-head`、`grid-2`、`grid-3`、`stats`、`stat`、`toolbar`、`button`、`button secondary`、`button danger`、`form-grid`、`field wide`、`muted`、`small`、`notice`、`notice warning`、`badge`、`badge good`、`badge warn`、`record-card`、`record-list`、`split`、`stack`、`prose`、`empty`、`bar`、`bar-fill`、`checklist`、`code-output`、`table-wrap`、`result`、`metric`。

交互：模块自己给root绑定事件、render，所有事件处理须try/catch错误并ctx.notify。不要使用内联事件/样式脚本、外部请求、CDN、innerHTML注入用户内容。不保存文件二进制到localStorage。DOM原生label/键盘/焦点兼容。中文日期和数值明确单位。演示数据与真实录入区分；真实不确定结果不假评分、不编造概率。

基础页顶会统一提供项目数据JSON导出/导入预览替换、恢复前备份和使用指引。各模块仍需自己的业务输出（报告、CSV、训练记录等）。若用户原始卡要求导入文件，则实现对应导入，不以全局JSON替代。

测试：每组tests/gX.test.mjs使用node:test；领域核心纯函数另文件logic.js便于覆盖边界和失败场景。测试数量不替代业务验收；给出浏览器具体操作，主Agent整体验证。各应用首版须有实际专用流程，不允许只有表单CRUD与介绍页。

参考：每组先完整读取自己的5张原卡，web检索原始参考（至少2个与该组功能有关的官方产品/开源），docs/research-gX.md记录看过的原文、采用方式和未复制资产。读取元宝技能后可搜索；初始主Agent已完成元宝查询，子Agent复用routeId。
